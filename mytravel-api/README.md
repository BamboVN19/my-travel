# MyTravel Project - Backend API

## 1. Yêu cầu hệ thống
- Docker & Docker Desktop
- Java 21 (JDK)
- IntelliJ IDEA

## 2. Cách chạy dự án
1. **Clone dự án về máy.**
2. **Khởi động Database:** Mở Terminal tại thư mục dự án và gõ:
   `docker-compose up -d`
   (Hoặc đơn giản là nhấn Run trong IntelliJ, Spring Boot sẽ tự bật Docker cho bạn).
3. **Chạy App:** Chạy file `MytravelApiApplication.java`.

## 3. Thông tin Database (Dành cho DBeaver)
- **Host:** localhost | **Port:** 5432
- **DB Name:** mytravel_db
- **User:** my_travel | **Pass:** travel
